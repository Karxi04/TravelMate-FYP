# Ink Wash UI Theme

The Traveller app, Tourism Operator website and Administrator website use the same visual family but remain separate applications.

Primary palette from the supplied design:

- Charcoal: `#4A4A4A`
- Soft grey: `#CBCBCB`
- Warm cream: `#FFFFE3`
- Blue grey: `#6D8196`

Usage:

- Charcoal: navigation/sidebar, headings, strong text
- Soft grey: borders, separators, inactive states
- Warm cream: highlighted cards, selected navigation, calm backgrounds
- Blue grey: primary buttons, icons, active controls
- White / off-white: main content background
