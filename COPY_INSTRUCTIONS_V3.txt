TRAVELMATE V3 - COPY / START INSTRUCTIONS

Use this V3 folder as the new code baseline.

FROM YOUR CURRENT WORKING PROJECT, COPY ONLY YOUR REAL CONFIGURATION:

1. traveller_mobile/android/
   -> copy the whole working Android folder into this V3 traveller_mobile/

2. traveller_mobile/lib/firebase_options.dart
   -> copy your real Firebase-generated file into this V3 traveller_mobile/lib/

3. backend_api/.env
   -> keep/copy your real backend environment file for future cloud/backend use

4. backend_api/serviceAccountKey.json
   -> keep/copy your real backend Firebase service account for future backend use

DO NOT copy your old whole lib/ folder over V3.
That would remove the new dynamic search, Assistant, Trips and Profile changes.

RUN THE STANDALONE TRAVELLER APP:

cd traveller_mobile
flutter clean
flutter pub get
flutter analyze
flutter run

For the default standalone Traveller build you do NOT need:
- python app.py
- adb reverse tcp:5000 tcp:5000

The USB cable is only needed while installing/debugging with flutter run. After the app is installed, its standalone functions do not depend on the development PC.
